# bluetti-power-watch

Допомагає ПК на Linux пережити вимкнення світла на станції BLUETTI.

[English](README.md)

Зроблено в Україні, де вимкнення світла стали буденністю. ПК живиться через
станцію BLUETTI. Ця невелика служба стежить за станцією через Bluetooth і
допомагає заряду протриматися довше, поки світла немає.

## Що робить

- Приблизно раз на хвилину читає станцію через Bluetooth LE. **Лише читає**:
  у станцію не записує нічого.
- **Немає світла** (напруга на вході нижча за 100 В два заміри поспіль):
  вмикає профіль `power-saver`, за бажанням приглушує монітор, показує
  сповіщення.
- **Світло повернулось**: повертає профіль живлення і яскравість.
- **Заряд низький**: сповіщення. **Заряд критичний**: акуратно вимикає ПК, але
  лише якщо ви це дозволили (`bluetti-power-watch arm`).
- **Станція застрягла**: після провалу напруги деякі станції перестають брати
  струм із мережі й далі живлять від батареї, навіть коли напруга повернулась
  (на екрані помилка E114). Сторож це помічає і просить перепідключити вилку.
  Поки станція застрягла, попередження про низький і критичний заряд та
  автовимкнення працюють так само, як без світла.
- «Станція не відповідає» **не** вважається вимкненням світла. Через брак даних
  нічого не вимикається.
- Віджет для KDE Plasma 6: заряд, напруга в мережі, потужність на вході й
  виході, на скільки вистачить заряду, налаштування порогів.

## Які станції

- **Перевірено:** BLUETTI Elite 320.
- **Має працювати, не перевірено:** моделі, профіль яких у
  [bluetti-bt-lib](https://github.com/Patrick762/bluetti-bt-lib) віддає напругу
  на вході: AC60, AC60P, AC70, AC70P, AC180, AC180P, AC180T, AC300, AC500,
  AP300, EB3A, EL10, EL30V2, EL100V2, EP500, EP500P, PR30V2, PR100V2,
  Handsfree 1. Якщо спробуєте, відкрийте, будь ласка, issue з виводом
  `bluetti-power-watch once`.
- **Не підтримуються:** моделі без напруги на вході (AC2A, AC2P, AC50B, AC200L,
  AC200M, AC200PL, EP600, EP760, EP800, EP2000): у них вимкнення світла не
  відрізнити від повного заряду.

## Встановлення

З AUR будь-яким помічником:

```sh
paru -S bluetti-power-watch
```

## Налаштування

1. Знайдіть свою станцію:
   ```sh
   bluetti-power-watch scan
   ```
2. Виберіть її за **повною назвою** (модель і серійний номер). Номер звірте з
   корпусом або застосунком BLUETTI: дві станції однієї моделі в квартирі
   трапляються, і сторож підключається лише до точно названої.
   ```sh
   bluetti-power-watch set-station EL3201234567890123
   ```
3. Перевірте, що читає:
   ```sh
   bluetti-power-watch once
   ```
4. Запустіть службу:
   ```sh
   systemctl --user enable --now bluetti-power-watch
   ```
5. За бажанням: правою кнопкою на панелі → *Додати віджети…* → **Станція BLUETTI**.
6. За бажанням: увімкніть автовимкнення ПК (нижче).

## Налаштування у файлі

`~/.config/bluetti-power-watch/config.json` (частину `station` записує
`set-station`):

```json
{
  "station": {"name": "EL3201234567890123", "model": "EL320", "encrypted": true},
  "power_saver": true,
  "brightness": 20
}
```

- `power_saver`: профіль `power-saver`, поки немає світла (за замовчуванням
  увімкнено, потрібен `power-profiles-daemon`).
- `brightness`: приглушити монітор до цього значення через `ddcutil`
  (за замовчуванням вимкнено).

**Пороги** задаються у віджеті (*Налаштувати…*) або в терміналі:

```sh
bluetti-power-watch set-thresholds --low 20 --critical 7 --stuck-minutes 5
```

Задавайте їх в одному місці: віджет записує свої значення щоразу, коли ви
застосовуєте їх у налаштуваннях. Нові пороги діють із наступного заміру, без
перезапуску.

Стан і помісячний журнал замірів лежать у `~/.local/state/bluetti-power-watch/`.

## Автовимкнення ПК

За замовчуванням вимкнене.

```sh
bluetti-power-watch arm      # вимикати ПК при критичному заряді без світла
bluetti-power-watch disarm
```

Вимикає через `systemctl poweroff`, а polkit дозволяє це для активної місцевої
сесії. Спрацьовує не частіше одного разу за вимкнення світла: якщо ви ввімкнете
ПК знову, поки світла ще немає, він не вимкнеться повторно, і сповіщення про це
скаже. Якщо станція тим часом зарядилась (світло було, поки ПК стояв
вимкнений), наступне вимкнення світла вважається новим.

Чесно: логіка покрита тестами, але справжнього вимкнення на критичному заряді на
ПК автора ще не було.

## Відомі обмеження

- На ПК автора одного разу завис USB-адаптер Bluetooth. Тоді сторож не може
  прочитати станцію і лише раз сповіщає про це, приблизно через 10 хвилин.
  Допомогло тільки повне знеструмлення ПК.
- Оцінка часу у віджеті рахується за даними Elite 320 (3200 Вт·год); для інших
  моделей вона приблизна.
- Лише одна станція і лише один читач водночас: дві програми, що читають ту саму
  станцію одночасно (наприклад, дві копії цієї служби), зривають одна одній
  читання.
- Застосунком BLUETTI на телефоні можна користуватись одночасно: автор стежить
  за станцією в застосунку, поки служба працює, і це не заважає.

## Приватність

Нічого не виходить за межі вашого ПК: без мережі, без телеметрії.
